This is a React + Vite portfolio application for Design Spartans.

## Getting Started

First, install dependencies and run the development server:

```bash
npm install
npm run dev
```

Create a `.env` file with:

```bash
VITE_API_BASE_URL=https://your-api-host.example.com
```

For backward compatibility during migration, the app also accepts:

```bash
NEXT_PUBLIC_API_BASE_URL=https://your-api-host.example.com
```

Open the local URL printed by Vite in your terminal to see the result.

Build for production with:

```bash
npm run build
```
